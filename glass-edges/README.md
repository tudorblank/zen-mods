# Glass Edges

macOS-style glass rims on Essentials, selected/hovered tabs, toolbar and sidebar buttons, and the URL bar.

- `--ge-strength` at the top of `userChrome.css` controls the intensity (0 = off).
- The rim on the compact sidebar's body is off by default. Set `glass-edges.compact-sidebar-body` to `true` in `about:config` to enable it.
