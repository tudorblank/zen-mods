# Zen Logo Menu

Replaces the toolbar's main menu button icon ("...") with the Zen logo (the three rings).

- **Colour**: *Auto* (default) uses the toolbar's icon colour, so it follows Zen's light/dark theme.
  In Sine's settings for this mod you can force *Dark theme (white logo)* or *Light theme (black logo)*.
- **Hover**: turns Zen's signature orange (`#F76F53`). Change `--zlm-hover-color` in `userChrome.css` to pick another colour.
